1. OVERVIEW & TECH STACK
===============================================================================
Execute the end-to-end implementation of a Retrieval-Augmented Generation (RAG) 
chatbot system. The architecture consists of a user portal for chatting 
and an admin portal for document management.

Backend Stack:
- Framework: Python FastAPI (Asynchronous processing)
- Relational DB: PostgreSQL (via SQLAlchemy ORM)
- Vector DB: ChromaDB or FAISS (Local persistence)[cite: 1]
- AI Layer: LangChain, OpenAI API (Embeddings + LLM chat generation)[cite: 1]

Frontend Stack:
- Framework: React / Next.js[cite: 1]
- Styling: Tailwind CSS[cite: 1]

Advanced Features to Implement:
- Token Streaming via Server-Sent Events (SSE)[cite: 1]
- Hybrid Search (BM25 Keyword Search + Vector Similarity Search)[cite: 1]
- Production Architecture: Strict FastAPI Dependency Injection (Depends())

4. DAY 2 TASKS: CORE RAG PIPELINE & FASTAPI ENDPOINTS
===============================================================================
Task 2.1: Implement Document Processing Ingestion Flow
- Write ingestion logic inside `backend/app/rag/pipeline.py` corresponding to the PDF workflow[cite: 1]:
  1. Parse PDF binaries using `pypdf` or LangChain loaders[cite: 1].
  2. Implement text splitting: Chunk Size = 500-1000 tokens, Overlap = 100-200 tokens[cite: 1].
  3. Generate embeddings using OpenAI's embedding model[cite: 1].
  4. Upsert vector arrays to ChromaDB and insert raw text chunks into the BM25 index[cite: 1].

Task 2.2: Implement Hybrid Search & Streaming Flow
- Inside `backend/app/rag/pipeline.py`, construct an `EnsembleRetriever` configuration:
  - Component A: ChromaDB Vector Similarity Search[cite: 1].
  - Component B: BM25 Keyword Search[cite: 1].
  - Merge strategy: Use Reciprocal Rank Fusion (RRF) to combine candidate chunks[cite: 1].
- In `backend/app/rag/stream_handler.py`, write an async generator that takes user queries, 
  retrieves context via the `EnsembleRetriever`, feeds it to an OpenAI ChatModel wrapper, 
  and streams tokens using Server-Sent Events (`StreamingResponse` with `text/event-stream` media type)[cite: 1].

Task 2.3: Build REST API Routes
- Use FastAPI Dependency Injection (`Depends()`) to inject PostgreSQL database sessions and VectorDB instances into all routes.
- Implement the following endpoints explicitly matching "RAG_Chatbot_Project_Plan.pdf"[cite: 1]:
  * `POST /upload-pdf`: Receives file binary, records state in database, runs async chunking/embedding[cite: 1].
  * `GET /documents`: Queries database for all file metadata[cite: 1].
  * `DELETE /documents/{id}`: Drops file record, drops vectors via document ID metadata filtering[cite: 1].
  * `POST /chat`: Orchestrates query embedding generation, retrieval, and streams back token responses[cite: 1].
  * `GET /chat-history`: Returns historical logs from the database sorted by timestamp[cite: 1].
  * `GET /health`: Basic operational validation returning up-time status[cite: 1].
